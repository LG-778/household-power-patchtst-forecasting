# PatchTST 论文解读与复现验证笔记

> 论文：Nie et al., *A Time Series is Worth 64 Words: Long-term Forecasting with Transformers*, ICLR 2023
> arXiv: https://arxiv.org/abs/2211.14730
> 配套项目：household-power-patchtst-forecasting（UCI 家庭用电数据集，小时级，L=168 → H=24）
> 说明：本笔记所有内容均经过"讲解→本人复述过关"流程。第四节验证表已于 test 收官后回填（2026-09-11）。

## 一、这篇论文在解决什么问题

2022 年 DLinear（Zeng et al.）证明：一个极简线性模型可以在多个基准上击败当时所有的时序 Transformer 变体（Informer / Autoformer / FEDformer 等），"Transformer 是否适合时序预测"被打上问号。

PatchTST 的回答：问题不在 Transformer 本身，而在**输入方式**。它不改 encoder 的任何零件（vanilla Transformer encoder），只改输入怎么进模型，就赢回了场面。

作者原话定调："Patching is simple but proven to be an effective operator."——价值在"极简"，没有发明新机制，只是把输入方式改对了。

## 二、三个核心设计

### 2.1 Patching（分块）

- 做法：把 lookback 窗口（而非整个数据集）切成若干 patch，每个 patch 作为一个 token 输入 Transformer。patch 长度 P=16、stride S=8（相邻 patch 重叠一半）；切分前将序列末值重复 S 次补齐，防止最后一个 patch 不满 P 个点被丢弃——末端是离预测目标最近、信息最值钱的一段。
- patch 数公式：N = ⌊(L−P)/S⌋ + 2。本项目 L=168、P=16、S=8 → N=21。
- 三重好处（论文摘要原文）：
  1. patch 内保留局部语义——模型看到的是"形状"而非孤立点；
  2. token 数从 L 降到约 L/S，注意力矩阵开销**平方级下降**（S=8 → 约 1/64）——消融表 7 中 Traffic 数据集"只有 CI 没有 P"的配置在 48GB 显卡上 batch=1 都爆显存，证明省算力是实践结论不是理论；
  3. 省下的算力可换更长的 lookback。
- 标题考据："64 Words"致敬 ViT 的 "An Image is Worth 16x16 Words"；PatchTST/64 即输入 64 个 patch（对应 L=512）。
- patch 长度的权衡：太细（P=1）退回 point-wise 老路、算力爆炸；太粗（P=L）只剩 1 个 token，注意力失效、局部形状被平均掉。P=16 是两端之间的甜点。
- 本项目视角：16 小时的 patch 大致对齐家庭用电的一个"行为片段"（晚峰+夜谷+早峰的一部分）；注意 24 小时才是完整日周期，patch 是片段不是周期。

### 2.2 Channel-Independence（通道独立）

- 正确定义：M 条单变量序列**共享同一套 embedding 和 Transformer 权重**，前向过程各自独立，最后拼接输出。类比：一位老师用同一套教案分别辅导 M 个学生，学生之间不许交流。
- 为什么隔离反而更好（附录 A.7 对照实验）：
  - 通道混合模型训练几个 epoch 即过拟合，通道独立模型可持续优化；
  - 共享权重 → 参数不变，有效训练样本翻 M 倍（样本效率）；
  - 噪声隔离：某个通道的噪声不会经 embedding 空间传染其他序列。
- 消融表 7（Electricity, T=96, MSE）：P+CI 0.130 < 只有CI 0.136 < 只有P 0.196 < 原始TST 0.205 —— 两个设计缺一不可；Traffic 上"只有CI"直接爆显存（patching 是前提，CI 是放大器）。
- 代价（作者承认，Conclusion 原文）：丢弃了变量间的相关关系，跨通道依赖建模列为 future work；附录给出的出路是在 CI 基础上叠加图神经网络等方法。
- 本项目视角：单变量 M=1，该设计自动成立；扩展到台区多户联合预测时它才成为关键选择，代价是户间相关性。

### 2.3 Instance Normalization（RevIN，可逆实例归一化）

- 五步链条：窗口进来 → 窗口内计算 μ、σ → (x−μ)/σ 归一化后切 patch 进模型 → 归一化空间输出预测 → 每步预测 ×σ+μ 还原原始量纲（"可逆"）。
- 与全局 scaler / BatchNorm 的区别：全局 scaler 用训练集统计量，测试期基线漂出训练范围即失效；BatchNorm 的 batch 统计量不稳定；RevIN 用窗口自身统计量，每个窗口"自我归零"，模型只学相对形状，水平由归一化层保管、预测后归还。
- 与项目硬约束的关系：全局 scaler 管基线模型特征、防训练/测试统计量泄漏；RevIN 是 PatchTST 内部窗口级操作、天然无泄漏。作用层级不同，不冲突。
- 边界：假设窗口内均值能代表当前水平。缓慢漂移有效；**窗口内发生突变**（如某周新装电采暖）时窗口均值是折中值，形状和水平都会被扭曲 → 残差放大。EDA 的按年日均负荷曲线即为漂移幅度提供证据。可选补救：变点检测 / 缩短 lookback。
- **本项目实测补充的第二条边界（夜间近零值弱信号区）**：夜间负荷近零时段，窗口归一化后有效信号弱、相对误差被放大——DL 模型夜间 nMAE 显著高于 XGBoost（PatchTST 0.657 / DLinear 0.705 vs XGBoost 0.421）。即「RevIN 救漂移、救不了近零值」。

## 三、输出头：Flatten + Linear Head（直接多输出）

- encoder 输出 21 个 patch 的表示，拉平成一根长向量，接线性层**一次输出全部 24 步**。第 17 小时的预测由全部 21 个 patch 的全局信息映射产生，而非由第 16 小时的预测推出。
- 与递归法的哲学差异：直接多输出让每个 horizon 独立地从全部历史信息里学；递归法 horizon 之间串行依赖、误差逐级放大（旧项目实测：递归第 1 小时 MAE 0.3943 → 第 24 小时 0.5761，放大 46%）。
- 代价：小时与小时之间的平滑性无显式约束，相邻小时预测可能跳变（误差分析观察点）。
- **验证结果（P5 已闭环）**：horizon vs MAE 双曲线（`outputs/p5/horizon_mae_dual_curve.png`）——PatchTST 直接多输出 h1→h24 涨幅 **+21%**（0.407→0.494），旧项目递归法 +46%，「直接多输出压平递归误差累积」成立。
- encoder 细节留痕：vanilla encoder（多头注意力+FFN+残差），论文脚注：用 BatchNorm 而非 LayerNorm；损失 MSE、通道平均。训练用 MSE、评估主指标 MAE(kW)，口径分开。

## 五、我没复现的部分与局限（诚实边界）

1. **自监督预训练未复现**：论文自监督优势在大数据集上才显著（摘要原文），本项目为 3.5 万点单户单变量序列，小数据场景预训练边际收益有限；GPU 6h 预算已用约 5h，预训练+微调路径超出时间盒。未来接入台区级多户数据、数据量上来后，这条路优先级重新评估。
2. **跨通道相关性**：CI 丢弃变量间相关关系（作者承认的 future work）。单户场景暂无影响；台区级多户联合预测时会丢掉户间相关性，可尝试作者建议的方向——CI 基础上叠加图神经网络建模跨通道关系。
3. **RevIN 对突变失效**：见 §2.3 边界一。
4. **RevIN 夜间弱信号区失效**：见 §2.3 边界二（本项目实测新增的边界）。
